# 账本城 · AI 小说与 IP 设定集创作

> 大连财经学院管理学院《人工智能工具应用实践》第 2 课实践成果：
> 用 AI 在 90 分钟内完成一篇三章小说《账本城》及其完整的 IP 设定集。

**《账本城》**是一座把「每一次选择」都记进公共账册的架空校园城：城中不使用货币，只使用「条目」——每写下一条，就必须划掉另一条。三章正文 2654 字，讲述记录员沈砚、抄写员阿桉、钟楼看守钟叔与寄存处学徒小满，如何在一枚三十年前的铜钥匙与半张撕落的旧纸之间，完成两笔迟到多年的「条目闭合」。

## 仓库用途

- **小说成品**：三章正文 + 世界观设定集 + 人物索引 + 单文件阅读版，可直接阅读或二次创作。
- **过程资产**：风格基线、伏笔回收表、连续性校对表等 12 项编号成果，展示一套可复用的 AI 小说工作流。
- **可复现**：素材、提示词库与自检脚本齐全，任何人可按相同流程复现或替换素材再做一篇。

## 生成方式（9 步工作流）

按课程网页的 9 步流程执行（提示词模板见 `materials/06_提示词库.md`）：

1. **风格基线**：归纳风格样章 → `00`；
2. **世界观**：固化 H1—H5 硬设定（每条写明检查方法）→ `01`；
3. **人物**：4 人小传 + 4×4 关系矩阵，不新增第 5 位具名人物 → `02/03`；
4. **大纲**：9 场景，第 1 章埋 F1/F2、第 3 章必须回收 → `04/05`；
5. **正文**：逐章生成，每章 ≥800 字、≥6 处对话、章末状态登记 → `06`；
6. **校对**：按 6 类检查表核验并真修订（本次发现 7 处矛盾，最关键的是 H4——划掉的条目只能在**别人**的账册里重抄一次）→ `07`；
7. **索引**：从正文抽取 4 类条目生成 JSON → `08/09`；
8. **封面与阅读版**：图像生成服务不可用，改用纯 CSS/SVG 同构图封面并如实标注 → `10/11`；
9. **自检打包**：脚本统计字数/行列/JSON，全部通过后打包 ZIP。

AI 参与说明：世界观、人物与大纲源自课程虚构素材；正文、索引、阅读版由 AI 按上述约束生成，人工完成约束设计、连续性裁定与验收。

## 使用方法

**阅读小说**

- 直接打开 `novel/11_阅读版.html`（零外部依赖，可离线双击打开）：左侧目录切换章节，顶部检索框输入「沈砚」「铜钥匙」等索引词，点击结果即高亮跳转。
- 或阅读 Markdown 源文件 `novel/06_正文_三章.md`。

**复现 / 自检**

```bash
python scripts/self_check.py        # 字数、对话、CSV 行列、JSON、禁用词、伏笔闭合
python scripts/build_reader.py      # 修改 06/08/09/10 后重建阅读版
```

**提交包**：`第2课_小说制作包.zip`（12 项编号成果，按课程命名规范打包，未纳入 git 追踪）。
