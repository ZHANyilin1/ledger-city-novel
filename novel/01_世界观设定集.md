# 01 · 世界观设定集 · 账本城

> 唯一来源：`01_世界观设定包.md`。本文件只做整理与补充检查方法，**不新增任何规则**；设定包未覆盖的信息一律标「待补充」。

## 一、基本设定

账本城是一座把「每一次选择」都记进公共账册的架空校园城。城中居民不使用货币，只使用「条目」：每写下一条，就必须划掉另一条。城里有三条街（东街、纸街、钟楼街）、一座旧钟楼、一间只在周五开放的寄存处。

## 二、硬设定（H1—H5）及检查方法

| 编号 | 规则 | 检查方法 |
| --- | --- | --- |
| H1 | 任何人每天只能在公共账册上写一条新条目，写第二条时第一条会自动消失。 | 逐章统计每个具名人物当日写条目次数；出现同日第二条时，核对前一条是否「自动消失」且无恢复描写。 |
| H2 | 寄存处只在周五傍晚开放，其余时间门是锁着的，任何人都不能进入。 | 检查所有寄存处场景的星期与位置：非周五不得写「进入寄存处内」，人物互动只能经小窗或门外。 |
| H3 | 旧钟楼的钟只在有人做出「不可撤回的选择」时敲响，其他时候永远静止。 | 每次钟声必须能对应一个明确做出不可撤回选择的人物与事件；其余场景出现钟声即违规。 |
| H4 | 划掉的条目无法恢复，但可以在别人的账册里被重新抄写一次。 | 每条被划掉的条目只允许一次「重新抄写」，且抄写目标必须是**别人的**账册；抄写后不得再抄第二次。 |
| H5 | 城中不允许出现「购买」「付款」「价格」这类与货币有关的说法。 | 全文检索禁用词表（购买、付款、价格、钱等），命中即违规。 |

## 三、地理与场所表

| 场所 | 特征 |
| --- | --- |
| 东街 | 长桌连成一排，人们在这里写条目 |
| 纸街 | 抄写员聚集，墙上是层层旧纸 |
| 钟楼街 | 安静，地面有钟摆投下的长影 |
| 寄存处 | 木门、小窗、只在周五开 |
| 旧钟楼 | 指针停在某个位置，无人知道是谁停的 |

## 四、时间线（6 行）

| 时间点 | 事件 |
| --- | --- |
| 周一清晨 | 公共账册换上新的一页 |
| 周二下午 | 纸街的抄写员开始整理上周条目 |
| 周三上午 | 钟楼无故被擦拭一遍，但钟没有响 |
| 周四傍晚 | 寄存处门口第一次出现排队的人 |
| 周五傍晚 | 寄存处开放，钟楼敲响一次 |
| 周六清晨 | 公共账册被收进档案柜 |

## 五、负面约束（3 条，本世界不可能发生的事）

1. 任何人用钱买东西或讨论价格。
2. 任何人把已经划掉的条目在自己账册里恢复。
3. 钟在没有「不可撤回的选择」时自己敲响。

## 六、待补充

- 旧钟楼指针停留的具体位置：设定包写明「无人知道是谁停的」，正文不指认。
- 城中人口规模与其他街区：设定包未提及，正文不出现。
