# 00 · 风格基线

> 依据：`04_风格样章.md`（课堂原创示例，仅归纳风格，不抄入正文）。归纳日期：2026-11-16。

## 一、风格特征卡（8 项）

| # | 维度 | 基线 |
| --- | --- | --- |
| 1 | 叙述人称 | 第三人称限制视角，镜头固定跟随沈砚，不进入他人内心 |
| 2 | 时态 | 过去时叙述，无内心独白的将来时铺陈 |
| 3 | 平均句长 | 6—18 字的短句为主，偶用一句长句收束段落 |
| 4 | 对话占比 | 约 20%—30%，对话单句短，多为一问一答或半句留白 |
| 5 | 段落长度 | 每段 1—3 句；一段只做一件事 |
| 6 | 常用意象 | 纸、墨、水痕、影子、铜器、钟声、撕口 |
| 7 | 语气 | 克制、留白；情绪不直接命名，只写动作与物件 |
| 8 | 叙事节奏 | 细节先行、解释靠后；每场以一个具体动作收尾 |

## 二、禁用词（6 个）

| 禁用词 | 理由 |
| --- | --- |
| 购买 | 违反 H5（世界无货币） |
| 付款 | 违反 H5 |
| 价格 | 违反 H5 |
| 钱 | 违反 H5 |
| 突然 | 破坏克制语气，节奏靠场景切换完成 |
| 竟然 | 带叙述者惊叹，违反克制基调 |

## 三、硬规则（2 条）

1. **设定不得旁白解释**：H1—H5 与世界观规则只能通过人物动作、对话与物件状态带出，禁止叙述者直接讲解。
2. **情绪不得直接命名**：不写「他很紧张/她很难过」，只写可观察的动作（数三下、系紧围裙带子、笔尖悬着不落）。
